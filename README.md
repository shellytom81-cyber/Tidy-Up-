# Tidy-Up-
 Smart File Organizer App 📂

An intuitive desktop application built in Python using **Tkinter** to cleanly organize cluttered directories (such as Downloads or Desktop) into categorized subfolders.

---

## 🌟 Features

- **GUI Interface:** Interactive directory selectors for Source and Destination paths with live progress logging.
- **Multithreaded Execution:** Smooth performance without frozen UI windows during bulk moves.
- **Categorization Engine:**
  - 💻 **Programming:** `.py`, `.java`, `.cpp`, `.js`, `.html`, `.css`, etc.
  - 📄 **Lab Reports & Docs:** `.pdf`, `.docx`, `.txt`, `.tex`, etc.
  - 📊 **Presentations & Spreadsheets:** `.pptx`, `.xlsx`, `.csv`, `.json`, etc.
  - 🖼️ **Images & Diagrams:** `.png`, `.jpg`, `.svg`, `.gif`, etc.
  - 📦 **Archives & Others:** `.zip`, `.rar`, `.exe`, etc.
- **Conflict Prevention:** Automatic renaming for duplicate files to guarantee data safety.

---

## 🚀 Running the App

### Requirements
- Python 3.7+ installed.

### Execution
Run the app script directly:
```bash
python app.py
```
